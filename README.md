# Bot Sindicatos Comercio — Descargas

Para instalar el bot en una PC nueva, bajá el archivo
**"Bot-Sindicatos-Comercio-vX.Y.Z-Instalador.zip"** de la última versión en
[Releases](../../releases/latest), descomprimilo y hacé doble clic en `Instalar.vbs`.

Para usarlo necesitás una clave de licencia. Contacto: nico.cabanettes@gmail.com

Las actualizaciones se instalan desde el mismo bot, con el botón **Actualizar**.
